# api-client — generated from backend OpenAPI

Everything here is generated from the backend's OpenAPI document. Change the backend contract and regenerate; hand edits are overwritten.

- Regenerate in the same change as any backend endpoint/DTO/enum change, so apps and backend never drift.
- Hand-written code is limited to thin setup (base URL, auth header injection, token refresh) and lives outside the generated folder.
- The generator tool is not chosen yet — ask before adding one.
